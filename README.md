# 📏 Simple Non-Contact Rangefinder in C++ (ESP8266 + HC-SR04)

Простий та надійний проєкт безконтактного ультразвукового дальноміра (лінійки) на базі мікроконтролера **ESP8266** (Wemos D1 mini / NodeMCU) та ультразвукового датчика відстані **HC-SR04**.

Проєкт вимірює відстань до об'єкта в сантиметрах у реальному часі та виводить дані у Serial Monitor (або на підключений дисплей).

---

## 🛠️ Компоненти та апаратна частина

* **Мікроконтролер:** ESP8266 (Wemos D1 mini або NodeMCU)
* **Датчик відстані:** Ультразвуковий модуль HC-SR04
* **Джерело живлення:** 5V USB

### 🔌 Схема підключення (Pinout)

| Модуль HC-SR04 | Пін ESP8266 | GPIO | Опис |
| :--- | :--- | :--- | :--- |
| **VCC** | **5V / VIN** | 5V | Живлення датчика (+5V) |
| **Trig** | **D1** | GPIO5 | Генерація ультразвукового імпульсу |
| **Echo** | **D2** | GPIO4 | Прийом відбитого сигналу |
| **GND** | **GND** | GND | Спільне заземлення |

> ⚠️ **Примітка:** Модуль HC-SR04 працює від 5V. Вхід Echo видає 5V сигнал. Більшість плат ESP8266 толерантні до 5V на цифрових пінах при коротких імпульсах, але для максимальної надійності можна використати дільник напруги (резистори $1\text{k}\Omega$ та $2\text{k}\Omega$) на лінії Echo.

---

## ✨ Особливості реалізації

- **Використання бібліотеки `NewPing`:** Забезпечує стабільне зчитування без зависань мікроконтролера при виході за межі діапазону.
- **Висока точність:** Автоматична фільтрація помилкових спрацьовувань та обмеження максимальної відстані.
- **Швидкість оновлення:** Вимірювання проводяться кожні $100\text{ мс}$ для плавності відстеження руху.
